01 • Introduction

What is a Stored Procedure?

A stored procedure is a precompiled SQL program that is stored in a database and can be saved and reused.

04 • Syntax

Creating a Stored Procedure

In SQL Server, use the CREATE PROCEDURE statement.

SQL Server / T-SQL CREATE 
CREATE PROCEDURE procedure_name
    @param1 datatype,
    @param2 datatype
AS
BEGIN

    -- SQL statements to be executed

    SELECT column1, column2
    FROM table_name
    WHERE columnN = @paramN;

END
05 • Parameters

Stored Procedure Parameters

Parameters allow us to pass input values to a stored procedure. This makes the same procedure reusable with different values.

📥 Input Parameter

@StudentID INT

@StudentID is the parameter name, while INT specifies that it stores an integer value.

🔄 How It Works

Student ID 2
→
@StudentID Input
→
Students Table

Example: If we pass StudentID = 2, the procedure searches for the student whose ID is 2.

06 • Simple Example

Stored Procedure Example

Let's create a simple stored procedure to find a student using their Student ID.

📋 Students Table

StudentID Name Course
1 Ram BIM
2 Sita BIM
3 Hari BCA

💻 Create Procedure

GetStudent SQL 
CREATE PROCEDURE GetStudent
    @StudentID INT
AS
BEGIN
    SELECT *
    FROM Students
    WHERE StudentID = @StudentID;
END

GetStudent is the procedure name, while @StudentID is the input parameter.

07 • Execution

Execute the Procedure

We can execute the stored procedure by passing a Student ID.

▶ Execute

Execute Procedure EXEC 
EXEC GetStudent
    @StudentID = 2;

Here, 2 is passed as the value of @StudentID.

📊 Output

StudentID Name Course
2 Sita BIM

Input: Student ID 2 → Procedure: GetStudent → Result: Sita, BIM

08 • Multiple Parameters

Using Multiple Parameters

A stored procedure can accept more than one input parameter.

💻 Create Procedure

CREATE PROCEDURE GetStudentByCourse
    @StudentID INT,
    @Course VARCHAR(20)
AS
BEGIN
    SELECT *
    FROM Students
    WHERE StudentID = @StudentID
      AND Course = @Course;
END

▶ Execute

EXEC GetStudentByCourse
    @StudentID = 2,
    @Course = 'BIM';

Both conditions must match: StudentID = 2 and Course = BIM.

09 • Deletion

Drop a Stored Procedure

To delete a stored procedure, use DROP PROCEDURE. 

DROP PROCEDURE procedure_name;

A safer option is to use IF EXISTS so the command does not produce an error if the procedure is missing. 

DROP PROCEDURE IF EXISTS procedure_name;
10 • Complete Example

Complete Example

Let's create a stored procedure that finds an employee using their Employee ID.

👨‍💼 Employee Table

EmployeeID Name Salary
101 Ram 35000
102 Sita 45000
103 Hari 40000

💻 Step 1: Create Procedure

CREATE PROCEDURE GetEmployee
    @EmployeeID INT
AS
BEGIN
    SELECT *
    FROM Employees
    WHERE EmployeeID = @EmployeeID;
END

▶ Step 2: Execute Procedure

EXEC GetEmployee
    @EmployeeID = 102;

📊 Step 3: Output

EmployeeID Name Salary
102 Sita 45000

EmployeeID 102 → GetEmployee → Search Employees table → Sita — Rs. 45,000

11 • Summary

Key Takeaways

A stored procedure is reusable SQL code stored in a database.
It can accept parameters to work with different values.
CREATE PROCEDURE creates a procedure.
EXEC executes a procedure.
DROP PROCEDURE removes a procedure.
Benefits include reusability, security, maintenance and potential performance improvements.
