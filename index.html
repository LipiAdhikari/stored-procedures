01 • Introduction

What is a Stored Procedure?

A stored procedure is a precompiled SQL program that is stored in a database and can be saved and reused.

04 • Syntax

Creating a Stored Procedure

In SQL Server, use the CREATE PROCEDURE statement.

SQL Server / T-SQL CREATE 
CREATE PROCEDURE procedure_name
    @param1 datatype,
    @param2 datatype
AS
BEGIN

    -- SQL statements to be executed

    SELECT column1, column2
    FROM table_name
    WHERE columnN = @paramN;

END

06 • Example

Creating an Example

Let's create a procedure called GetCustomersByCity.

GetCustomersByCity SQL 
CREATE PROCEDURE GetCustomersByCity
    @City nvarchar(50)
AS
BEGIN

    SELECT *
    FROM Customers
    WHERE City = @City;

END

08 • Multiple Parameters

Multiple Parameters

A stored procedure can accept more than one parameter.

CREATE PROCEDURE GetCustomersByCity
    @City nvarchar(50),
    @PostalCode nvarchar(10)
AS
BEGIN

    SELECT *
    FROM Customers
    WHERE City = @City
      AND PostalCode = @PostalCode;

END
City = 'London'
PostalCode = 'WA1 1DP'

09 • Deletion

Drop a Stored Procedure

To delete a stored procedure, use DROP PROCEDURE. 

DROP PROCEDURE procedure_name;

A safer option is to use IF EXISTS so the command does not produce an error if the procedure is missing. 

DROP PROCEDURE IF EXISTS procedure_name;

11 • Summary

Key Takeaways

A stored procedure is reusable SQL code stored in a database.
It can accept parameters to work with different values.
CREATE PROCEDURE creates a procedure.
EXEC executes a procedure.
DROP PROCEDURE removes a procedure.
Benefits include reusability, security, maintenance and potential performance improvements.
